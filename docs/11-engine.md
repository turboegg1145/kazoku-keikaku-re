# 主循环（`rust/src/engine.rs`）

## 一句话

把「虚拟机 → 渲染层 → 音频混音器」串成一台能跑的机器：每帧跑一批指令，
遇到需要等玩家的地方就把控制权交出去。

## 引擎的等待机制（核心）

```
VM 对象 +0x20 = 当前待执行的指令号
  = -1  → 下一帧取新指令        （处理函数调了 FUN_00434EB0）
  ≠ -1  → 下一帧重新执行同一条  （处理函数没调 FUN_00434EB0）
```

**哪个指令处理函数不调 `FUN_00434EB0`，脚本就卡在那条指令上。**

本仓库的对应实现：

- `Vm::step()` 里 `exec` 返回 `Ok(true)` 且 `block_requested` 为真时，把 `code` 退回指令开头，
  置 `blocked = true`，并记下 `blocked_end`。
- `Vm::unblock()` 把 `code` 跳到 `blocked_end`——等价于引擎里输入处理函数补调一次 `FUN_00434EB0`。
- 批量 dump 时 `block_on_input = false`，不阻塞，否则原地死循环。

## 哪些指令会阻塞

| 指令 | 地址 | 结论 |
|---|---|---|
| `0x2B` 台词 | `0x437530` | **阻塞**。函数写完文本直接 `ret`，不调 `FUN_00434EB0` |
| `0x18` 选项输入（鼠标模式） | `0x4186C0` | **阻塞**。模式 0 不推进 PC |
| `0x85` 输入轮询 | — | **不阻塞**，脚本自己循环轮询。主循环用 `poll_wait` 识别 |

`0x2B` 的反汇编（`0x437530`）：

```asm
437530: push ecx / push esi
437534: call 0x434960            ; 取文本指针
437569: call 0x414380            ; 消息窗口设置文本
43756e: mov eax,1 / ret 4        ; 直接返回，没有 FUN_00434EB0
```

所以「台词挂住等点击」是**指令级**的阻塞，不是窗口自己等。
这也解释了为什么每句台词后面都跟着 `0x86`（INPUT_RESET）——那是把推进用的那次点击清掉。

## 状态机

```rust
pub enum Wait {
    Run,           // 本帧预算跑完，还能继续
    Text,          // 台词在打字，VM 已阻塞
    Input,         // 等一次点击
    Choice(usize), // 有选项窗打开，等点某一项
    Halt(Halt),    // 脚本结束
    Failed(String),
}
```

`pump()` 跑指令 → `drain()` 分发事件 → 遇到 `vm.blocked` 就按当前状态算出 `Wait`。
`0x85` 连续 32 次拿不到输入且期间没有任何新事件，也判定为「在等玩家」。

## 台词打字机

`Line { text, shown, total }`，`tick(dt_ms)` 按 `speed`（字符/秒）推进。
第一次点击把整句显示完，第二次点击才推进脚本——和原版一致。

## 音频接线

| 事件 | 处理 |
|---|---|
| `Bgm{name,mode}` | 从 WMSC 解码并播放（mode 1 = 单次，其余循环） |
| `BgmVolume` / `BgmLevel` | 调音量；`BgmLevel(0)` 淡出停止 |
| `SeLoad` / `SePlay` / `SeStop` | 按槽号管理，同槽再播打断旧的 |
| `Voice` / `Text{voice}` | 从 VOICE1/2 解码，单路，新语音打断旧语音 |

解码结果按 `归档/名字` 缓存，避免同一段语音反复解码。

## 归档懒加载

`Archive::open` 现在只读目录（几十 KB），成员按需 `seek + read`。
之前是整份读进内存：VOICE1 217MB + VOICE2 206MB + GGD 338MB，
在机械盘上冷启动要 5 秒以上。改完 `kzn play` 冷启动 0.7 秒。

## 还没对上的地方

- 选项循环：脚本每轮都先 `0x18` 模式 1（清高亮）再模式 3（确认），
  高亮只能由鼠标移动设置。主循环目前还没有「鼠标移到选项上」这条路径，
  所以 `kzn play` 在选项处会一直转。下一步要补：鼠标位置 → 选项命中 → `vm.hover`。
