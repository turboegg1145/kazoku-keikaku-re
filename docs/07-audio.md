# 07 · 音频

## 1. 数据在哪

| 归档 | 成员数 | 格式 | 用途 |
|---|---:|---|---|
| `WMSC` | 27 | OGG Vorbis | BGM，成员名 `02.OGG` … |
| `SE` | 136 | OGG Vorbis | 音效，成员名 `SE001.OGG` … |
| `VOICE1` | 11215 | OGG Vorbis | 语音，成员名 `ANA0001.OGG` … |
| `VOICE2` | 11081 | OGG Vorbis | 语音，成员名 `KDM0001.OGG` … |

全部是标准 OGG，不需要解码器逆向，直接喂给平台解码器即可（iOS：`AVAudioPlayer` / `AVAudioEngine`）。

## 2. 剧本怎么写

### `0x70 <名字\0> <u8 模式>` — BGM

脚本里的名字是 `25.wav` 这种，引擎用 `_splitpath` 只取主名，再拼上 `.OGG`，
然后去 `WMSC` 里找 `25.OGG`。所以**扩展名是假的，别照着找 .wav**。

模式：

| 模式 | 引擎状态字 | 行为 |
|---|---|---|
| 0 | 2 | 循环播放 |
| 1 | 1 | 单次播放 |
| 2 | 4 | 循环，从当前位置继续 |
| 其它 | 0 | 停止 |

引擎还会把状态写进「通道 0x21」，供 `0x3A 0x0D` 之类的等待条件查询。

### `0x71 <u8 循环> <操作数 音量>` — BGM 参数

第一个字节为 0 表示循环；音量是标准操作数编码（可以是变量、随机数、符号扩展）。

### `0x72 <操作数 音量>` — BGM 音量

值 < 1 时引擎走「停掉通道 0x21」的分支。

### `0x78 <名字>` — 语音

载荷就是 `VOICE1`/`VOICE2` 里的成员主名，例如 `ONK0001`。
它不立即播放，而是挂在**下一条 `0x2B` 台词**上一起播。

### `0xF0 <u8 归档号> <名字>` — 切换归档

实测出现四种：`1 GGD`、`1 GGD2`、`4 VOICE1`、`4 VOICE2`。

- 归档号 1 = 图像归档：之后 `0x56` 注册的图名去这个归档里找；
- 归档号 4 = 语音归档：之后 `0x78` 的语音去这个归档里找。

这条很关键——同一个剧本会来回切 `VOICE1`/`VOICE2`（不同角色分包），
不实现就会有一半语音找不到文件。

## 3. 移植版要做的

1. 事件流里已经有 `BGM`/`BGM_VOL`/`BGM_LEVEL`/`VOICE`/`VOICE_ARC`；
2. 音频后端按事件驱动：`BGM` 切歌（同名不重播）、`BGM_VOL` 调音量、`BGM_LEVEL 0` 停；
3. 语音跟台词同步：台词开始打字时播，跳过/自动时切断；
4. OGG 直接交给平台解码器，不需要自己写解码。
